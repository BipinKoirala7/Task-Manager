# MERN Task Manager

## Run it

1. Pull or clone or download the repo (if downloaded, unzip it).
2. Install everything from the root folder:

   ```sh
   npm run install-all
   ```

3. Create `backend/.env` and add your MongoDB and JWT values.
   You would need two variables `` MONGODB_URL `` & `` ACCESS_TOKEN_SECRET ``
5. Start the app from the root folder:

   ```sh
   npm run dev
   ```

6. Open `http://localhost:3000` in your browser.
